# 🌸 Supabase Live Guestbook Setup Guide (2 Minutes, 100% Free)

To make your guestbook store messages permanently so **anyone visiting your site worldwide can see and sign it**, follow these 3 simple steps:

---

### Step 1: Create a Free Supabase Project
1. Go to [https://supabase.com](https://supabase.com) and click **Start your project** (sign in with your GitHub account `arpi404`).
2. Click **New Project**.
3. Choose a name (e.g., `webiee-guestbook`) and a database password.
4. Select any free region close to you and click **Create new project** (takes ~1 minute).

---

### Step 2: Create the Guestbook Table (Copy & Paste SQL)
1. In your Supabase project dashboard, click on the **SQL Editor** tab (icon with `>_` on the left sidebar).
2. Click **New query** (or **+**).
3. Paste the following SQL and click **Run**:

```sql
-- 1. Create the guestbook table
create table public.guestbook (
  id bigint generated by default as identity primary key,
  name text not null,
  message text not null,
  date text default to_char(now(), 'Mon DD, YYYY, HH12:MI AM'),
  likes integer default 1,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 2. Enable Row Level Security (RLS)
alter table public.guestbook enable row level security;

-- 3. Allow anyone visiting your site to read guestbook messages
create policy "Allow public read" on public.guestbook
  for select using (true);

-- 4. Allow anyone visiting your site to post guestbook messages
create policy "Allow public insert" on public.guestbook
  for insert with check (true);

-- 5. Allow anyone to like messages
create policy "Allow public update likes" on public.guestbook
  for update using (true);

-- 6. Insert cute starter message
insert into public.guestbook (name, message, date, likes)
values ('Tester ✨', 'Welcome to the live shrine guestbook! Anyone can sign here! ♡', to_char(now(), 'Mon DD, YYYY, HH12:MI AM'), 1);
```

---

### Step 3: Copy Your API Keys to `index.html`
1. In your Supabase dashboard, go to **Project Settings** (gear icon ⚙️ at bottom left) -> **API**.
2. Find:
   - **Project URL**: (e.g., `https://xyzcompany.supabase.co`)
   - **Project API keys** -> **`anon` `public`** key (starts with `eyJ...`)
3. Open `index.html` in your project and paste them:
   ```html
   <script>
     window.SUPABASE_URL = 'https://xyzcompany.supabase.co';
     window.SUPABASE_ANON_KEY = 'eyJhbGciOi...your_anon_key_here...';
   </script>
   ```
4. Save, commit, and push!

---

### ✨ That's it!
Your guestbook will now be connected to a live cloud database with **instant real-time updates**! When any visitor signs from their computer or phone, their message is saved permanently and shows up immediately for everyone!
